# Codomax Module 02 - Data Analysis with Python

## Overview
This project demonstrates basic data analysis using Python, Pandas, NumPy, and Matplotlib.

## Tasks Completed
- Imported Pandas and NumPy
- Created and imported a sample CSV dataset
- Explored dataset structure and statistical summaries
- Checked missing values and duplicate records
- Calculated highest, lowest, and average marks
- Performed department-wise analysis
- Created a bar chart using Matplotlib
- Practiced NumPy array operations
- Filtered and sorted student records
- Exported analysis results to CSV

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- GitHub

## Dataset
A small sample student dataset created for learning and practice. It is not real-world student data.

## Outcome
Practiced fundamental data analysis, data cleaning, numerical operations, and data visualization.
